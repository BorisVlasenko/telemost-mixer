# Telemost Mixer

Компактная панель (и трей) для одновременной работы с несколькими окнами Яндекс Телемоста на Linux (KDE + PipeWire).

Глушит микрофон и звук **на уровне PipeWire** (`pactl`), не кликая по UI Телемоста. Окна браузера можно свернуть — управление остаётся на панели.

## Возможности

- Динамическое число каналов: сразу две строки + кнопка «Добавить канал»
- Выпадающий список учеников из JSON с сайта diobuch (имя + постоянная ссылка)
- ★ (говорить только в этот канал), копирование ссылки, закрытие окна, убрать строку, мик / звук
- Ползунок громкости на каждый канал (0–150%)
- Запуск / закрытие окон Яндекс.Браузера (`--app` + отдельные профили) **без пауз** между окнами
- Камера отключена флагом `--disable-video-capture`
- Трей: показать панель, править `channels.json`, перечитать каналы, загрузить список учеников

## Требования

- Linux, PipeWire / PulseAudio (`pactl`)
- Яндекс.Браузер (`yandex-browser` в `PATH`)
- Python 3 + PyQt6 (`python3-pyqt6` в Debian/Ubuntu/Kubuntu)

## Установка

```bash
git clone https://github.com/BorisVlasenko/telemost-mixer.git
cd telemost-mixer
cp channels.example.json channels.json
cp students.example.json students.json
# или скачайте «Список для микшера» из кабинета преподавателя на сайте
python3 mixer.py
```

Опционально: скопируй `telemost-mixer.desktop` в `~/.local/share/applications/` и поправь путь к `mixer.py`.

Профили браузера: `~/.local/share/telemost-mixer/ch1`, `ch2`, …

## Список учеников с сайта

В кабинете преподавателя → «Ученики» → **«Список для микшера»** → сохраните `telemost-students.json`.

В трее микшера: **«Загрузить список учеников…»** и укажите файл. После этого в каждой строке выбираете ученика — подставляется его ссылка.

Путь к файлу запоминается в `channels.json` (`students_file`). После смены мёртвой ссылки или нового ученика скачайте список снова.

## Важно

- Mute идёт через PipeWire: в UI Телемоста иконка микрофона может остаться «вкл».
- Имя на встрече Телемост часто просит вручную — панель его не подставляет.
- `channels.json` и `students.json` в git не коммитятся (личные ссылки). В репозитории — `*.example.json`.
